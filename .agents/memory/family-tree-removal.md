---
name: Family-tree removal policy
description: Confirmed product rule for removing a person from the saved family tree.
---

When a person is removed from the saved family tree, also remove that person’s descendants.

**Why:** The user selected this behavior when asked how real family-tree removal should work.

**How to apply:** Use this rule for persistent deletion behavior and its confirmation UI. The design preview remains local-only and does not delete saved records.
